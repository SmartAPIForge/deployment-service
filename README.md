# deployment-service

1. Купили новый сервер
2. Настраиваем ключи

Примерный вариант:
На локальной машине:
1. ssh-keygen -t rsa -b 4096 -C "example@mail.ru" — создаем приватный и публичный ключи (важно: без пароля).
2. ssh-copy-id -i ~/.ssh/id_rsa.pub user@host — добавляем публичный ключ на удаленный сервер, может потребоваться ввод пароля
